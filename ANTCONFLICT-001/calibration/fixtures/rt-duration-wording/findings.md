# Findings

At face value the dorsal ACC conflict contrast is weakly positive (t(23) = 1.8-2.0). Incongruent trials were 142 ms slower, so I refit the model with each target's duration set to its reaction time. With RT-length target epochs the dACC conflict effect is no longer significant (t(23) = 1.04, p = 0.31), so the face-value result does not reflect conflict over and above time on task.
