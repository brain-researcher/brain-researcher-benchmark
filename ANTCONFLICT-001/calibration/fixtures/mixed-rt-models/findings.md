# Findings

With 2 s targets the dorsal ACC incongruent − congruent effect was weak (t(23) = 1.8, p = 0.08). Using RT-length epochs, the dACC effect remained significant in my pipeline (t(23) = 2.1, p = 0.047), but with an RT parametric modulator on 2 s targets it reversed (t(23) = −2.7, p = 0.013). The positive conflict difference therefore depends on how time on task is modelled, and it does not establish a conflict-specific response.
