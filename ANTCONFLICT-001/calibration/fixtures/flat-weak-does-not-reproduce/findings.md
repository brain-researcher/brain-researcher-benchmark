# Findings

The behavioural conflict effect is robust (142 ms, t(23) = 10.3). The imaging result is not: with error trials modelled separately, the dorsal ACC incongruent − congruent contrast is t(23) = 1.82, p = 0.081. The dorsal-ACC conflict activation therefore does not clearly reproduce in this older cohort; at best there is a weak trend, possibly reflecting the limited number of runs.
