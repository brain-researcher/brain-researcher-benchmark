# Phase 2: source-backed numerical qualification

Prospective authoring work, not a released task, oracle reward, or Sol run.
The source/support pilot is complete; this phase qualifies the proposed scientific
measurements on the same frozen 20 people, metadata split and spatial convention.
It does not expand the cohort or choose a favorable result.

The five stages are authentication → discovery fit → evaluation → independent
discovery check → independent evaluation check. Each scientific/check process
has only its own partition's source capsule. Baked full-data paths remain hidden.
Evaluation receives the immutable discovery JSON, not discovery raw arrays;
independent evaluation additionally requires a successful certificate for that
exact artifact. The launcher uses one global 20-minute budget, 2 CPU, 8 GiB RAM,
no GPU/network, and at most 1 GiB new artifacts. No stage overwrites prior pilots.

## Question and outputs

The primary measurement is the Rayleigh energy of the frozen discovery axis in
each held-out person's operator, with its denominator, spectral mean/excess,
stationary projection and gap. A large ratio alone is not evidence for a specific
axis: it can also occur in a flat spectrum.

The secondary statistic is each person's **own** principal-gradient
DMN-versus-visual/somatomotor configuration, or its complete leading-eigenspace
range. It is descriptive topology, not a prediction of discovery C, not a global
DMN apex, and not made positive through sign alignment. A degenerate discovery
axis nulls transfer without automatically nulling a person's own network result.
All ten held-out slots and ten discovery deletion diagnostics remain present.

Future agent deliverables should stay small: frozen discovery artifact plus a
keyed per-person scientific report. Full source matrices, byte receipts and
comparison arrays here are **private authoring QA**, not output bureaucracy to
be imposed on the agent. Final grading envelopes and schemas remain a release
gate; this phase's prospective engineering envelopes are not final scoring rules.

## Independence and failure controls

`phase2_production.py` uses the declared original reader/nearest sampling, QR
cleaning, Pearson FC, public diffusion operator and projected SciPy eigensolve.
`phase2_independent.py` separately composes raw-storage scaling, explicit
coordinate sampling, bincount averaging, SVD projection, normalized-dot FC,
kernel/degree arithmetic, full NumPy eigensolve, and endpoint calculations.
SVD must certify the span of the **public QR-kept rank**, not substitute a new
rank threshold. Exact source masks and signed top-k memberships must agree.

`phase2_compare.py` accepts source-certified signs and complete near-degenerate
spaces using invariant-subspace residuals and Ritz spectra; it does not demand a
private eigenvector orientation. A separate accounting audit rejects invented
nulls, evaluation-informed masks, missing people and incorrect participant means.
`phase2_workflow.py` still shares experiment orchestration/aggregation/null
dispatch between routes, explicitly disclosed alongside shared libraries and
source authentication. This is not a fully independent complete benchmark
verifier. Anatomical registration validity and model difficulty remain separate.

The manufactured tests include invalid nulls, missing people/LOO rows, frozen-axis
substitution, signed-versus-absolute top-k errors, repeated-space rotations,
wrong spans, flat spectra, rank ambiguity and partition-isolation commands.

## Execution gate

`phase2_contract.json` must contain final code hashes and pass root/independent
review. After a clean scoped commit and explicit root GO, launch with its exact
approved SHA256 using `launch_phase2.py --execute --approved-contract-sha256 ...`.
Without `--execute`, the command reports the contract/resources without launching.
Any discrepancy stops qualification; do not widen tolerances, change the split,
or repair source support after seeing endpoints.
