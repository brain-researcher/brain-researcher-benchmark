# Release implementation review — 2026-10-04

All changes are new files under `release_v1/`; the original task and qualified
redesign files are unchanged. Nothing here claims a completed oracle run or
empirical difficulty. Root owns packaging, image/runtime qualification, commits,
Harbor execution, source-backed fixture execution and any later model run.

## Implemented

- Compact public two-file interface: a certified discovery artifact plus a
  self-contained one-shot held-out evaluator. Participant measurements, fixed
  support and ten discovery deletion diagnostics are required; raw arrays,
  source hashes and private authoring matrices are not submission chores.
- The public scientific contract keeps the frozen estimator and data, allows
  negative/mixed C, separates operator-energy transfer from individual network
  configuration and declares spatial/population/holdout limitations.
- Native installed Harbor 0.17.1 separate-verifier configuration validates.
  The final agent image has a clean Ubuntu ancestry; only runtime `/usr`,
  alternatives, public CA certificates, discovery capsule and public contract
  are copied. Private references and held-out signals are verifier-only.
- The root-owned verifier validates bounded regular snapshots, duplicate-free
  finite JSON, fixed identities/null reasons, and the source eigen-residual of
  the discovery axis. Either sign is accepted. Held-out reference arithmetic
  uses the accepted axis, not a secret canonical orientation. Certified
  serialization norm roundoff is accepted and the oracle locally normalizes it.
- Submitted Python is never imported into the trusted process. It executes as
  UID/GID 61616 in a chroot with no proc/device/socket/private paths, no inherited
  descriptors, no_new_privs and explicit resource limits. The trusted parent is
  a child subreaper, kills dedicated-UID descendants and verifies cleanup before
  parsing candidate results. The root runtime adapter must enforce tmpfs/cgroup
  caps, fail-closed agent stop and separate agent/verifier images.
- Packaging authenticates exact prior qualification receipts/arrays, code and
  each partition's original source files. It does not rerun a scientific search.
  Private numerical references inherit the earlier independent qualification;
  this is not a new fully independent scientific replication.
- Thirteen source-backed fixtures are prepared by `controls.py`: independent
  arithmetic, sign equivalence, norm roundoff, explicit isolation probes and an
  orphaned setsid descendant (five expected positive); empty, naive axis,
  held-out-informed support, fabricated transfer, test-optimal substitution,
  unjustified blanket null, missing person and wrong configuration
  interpretation (eight expected negative).
